# JavaScript Learning Journey

A collection of JavaScript learning exercises and practice projects, starting from fundamental concepts to DOM manipulation and event handling.

## About This Repository

This repository documents my learning journey in JavaScript. It contains exercises, experiments, and small challenges created while learning JavaScript fundamentals and practicing how JavaScript interacts with HTML elements.

The exercises are organized into separate folders based on the topics being studied.

- Conditional Statements (`if`, `else if`, `else`)
- Loops (`for`)
- Arrays
- Functions
- Objects and Arrays of Objects

### DOM (Document Object Model)
- DOM Selection
- Selecting Multiple Elements

### Events & User Interaction
- `onclick`

## How to Run

1. Install [Visual Studio Code](https://code.visualstudio.com/) or another code editor.
2. Clone or download this repository.
3. Open the project folder in your code editor.
4. Open the desired folder and locate its HTML file.
5. Open the HTML file in a web browser.

You can also use the **Live Server** extension in Visual Studio Code to run the HTML files locally.

For exercises that use `console.log()`, open the browser's Developer Tools and check the Console tab.
